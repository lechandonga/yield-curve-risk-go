# yield-curve-risk-go

完全本地运行的收益率曲线构建与利率风险计量引擎。行情只来自本地报价数据，
不接任何外部服务；曲线构建、风险对账与在线更新在脏数据与并发条件下给出
可解释、可复现的结果。

## 包结构

- `quote/` — 本地报价模型与确定性的脏数据处理规则
- `curve/` — 折现曲线构建、任意期限查询、外推与自洽重定价
- `risk/`  — 固定现金流定价、关键期限敏感度（KRD）、平行/斜率/曲率情景与对账
- `engine/`— 版本化曲线服务：原子发布、失败回退、并发一致性

## 报价与曲线约定

- 报价为**连续复利零息利率**，含 `Bid`/`Ask`，曲线使用中间价 `Mid=(Bid+Ask)/2`。
- 期限字符串支持 `D/W/M/Y`（ACT/365），如 `6M`、`10Y`；非法期限直接报错。
- 折现因子 `DF(t) = exp(-r(t)·t)`；节点之间对零息利率做**线性插值**。
- 曲线对输入报价**自洽重定价**（`Curve.RepriceQuotes` 误差为 0，仅浮点舍入量级）。
- 构建时校验折现因子跨节点严格递减（隐含远期为正）；出现套利形态时
  整个构建失败并给出 `Structural` 原因，不会产出带病曲线。

## 脏数据与失败处理策略

所有规则确定性执行，同一份报价集合在任何时刻、任何并发下结论一致：

| 情况 | 处理 | 原因码 |
|---|---|---|
| 字段缺失（ID/期限/时间戳） | 该条拒绝 | `MISSING_FIELD` |
| 期限非法 | 该条拒绝 | `INVALID_TENOR` |
| 买卖价倒挂 bid>ask | 该条拒绝 | `INVERTED_MARKET` |
| 行情过期（超过 `Policy.MaxAge`） | 该条拒绝 | `STALE` |
| 同期限重复（中间价差 ≤ `ConflictTolerance`） | 取时间戳最新者，并列取 ID 字典序最小者 | — |
| 同期限冲突（中间价差 > `ConflictTolerance`） | **该期限整体拒绝**，每条相关报价各记一条 | `CONFLICT` |

默认（`AllowDirtyBatch=false`）批次内出现任何问题即整体构建失败，返回
`BuildError` 列出全部原因；没有任何静默择一或部分应用。

## 外推策略

`curve.Config.Extrapolation` 可配置：

- `ExtrapolateFlatZero`（默认）：区间外保持端点零息利率不变，稳定且单调；
- `ExtrapolateError`：区间外查询显式报错。

## 风险对账口径与容差

- 关键期限敏感度采用**三角形关键期限平移**：在关键期限处为 1 个 bump，
  向相邻关键期限线性衰减到 0；首末关键点之外保持满 bump。因此各 KRD
  平移向量在每个节点上**精确加总为平行平移**。
- 对账口径：`sum(KRD 重估变化)` 对比 `平行冲击重估变化`，容差
  `RevalConfig.Tolerance` 可配置。
- 两者之差是 O(BumpSize²) 的凸性残差（分别冲击 vs 联合冲击的非线性差异），
  因此容差应与 bump 匹配：如 `BumpSize=1e-5` 配 `Tolerance=1e-6`。
- 超容差时返回 `ReconcileError`，同时暴露 KRD 加总、平行重估、差异与容差，
  并仍返回完整 `Report` 供诊断——绝不静默取近似值。

## 并发一致性模型

- 当前版本通过 `atomic.Pointer` 发布：读者只能看到**完整的旧版本或完整的
  新版本**，不存在半更新状态；已发布的 `Version`/`Curve` 不可变，可安全并发读。
- 更新由互斥锁串行化：先完整校验并构建，成功才原子交换；**构建失败保留上一
  可用版本**，失败原因记入 `Engine.Failures()` 并返回给调用方。
- 历史版本查询由 `RWMutex` 保护，返回不可变快照；并发更新、读取、历史查询
  同时进行不会数据竞争、死锁或互相矛盾（race 检测下验证）。

## 本地验证

```sh
# 全部单元测试（verbose 日志可见各业务用例与结果）
go test ./... -v

# 并发用例在 race 检测下运行
CGO_ENABLED=1 go test ./... -race
```

测试覆盖：

- `quote`：脏报价逐类拒绝（缺字段/坏期限/倒挂/过期）、重复报价确定性归并、冲突整期限拒绝；
- `curve`：自洽重定价、区间内 DF 严格递减无套利、两种外推模式、脏批次确定性失败、套利形态拒绝、结果可复现；
- `risk`：定价可复现、KRD 与平行冲击对账通过、超容差显式报错、平行/斜率/曲率情景、KRD 平移精确加总为平行；
- `engine`：版本发布与历史查询、失败回退、混合批次原子拒绝、并发更新/读取/历史查询一致性（`-race` 通过）。
